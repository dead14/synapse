
## UI/UX Rules
- Every time we build a new UI feature, first check the TailAdmin Pro template to see if a suitable component exists. If it does not exist, explicitly confirm this with the user before building a custom one. Any custom built components MUST strictly follow the design concepts and aesthetics of the TailAdmin Pro template.

## Workflow Rules
- Every time a feature is updated, added, or significantly modified, you MUST automatically stage and commit the changes to the Git repository. Do not skip this step; it is a hard requirement.
